Build the completion-portfolio optimizer (FR-4.5) using scipy SLSQP, then build the pipeline orchestrator that chains all Plan 01 primitives into a single `compute_position_size()` call producing the final risk-controlled position size for one signal.

Output: Two new modules — `completion.py` (scipy SLSQP optimizer) and `pipeline.py` (the orchestrator) — plus their tests. scipy and numpy added to requirements.txt.

    ```python
    def optimize_completion_weights(
        instrument_betas: dict[str, dict[str, float]],
        # e.g. {"IVE": {"Mkt-Rf": 0.97, "SMB": -0.18, "HML": 0.05}, "IYR": {...}}
    ) -> CompletionAllocation:
    ```

    Implementation:
    - Use `scipy.optimize.minimize` with `method='SLSQP'`.
    - Decision variables: w = [w_IVE, w_IYR] as floats.
    - Objective: sum of squared deviations from FF3_TARGETS.
      ```python
      def objective(w):
          achieved = {f: w[0]*instrument_betas["IVE"][f] + w[1]*instrument_betas["IYR"][f] for f in ("Mkt-Rf","SMB","HML")}
          return sum((achieved[f] - FF3_TARGETS[f])**2 for f in ("Mkt-Rf","SMB","HML"))
      ```
    - Equality constraint: `w[0] + w[1] == float(COMPLETION_WEIGHT)` (sleeve sums to 23%).
    - Bounds: `[(0.0, float(COMPLETION_WEIGHT)), (0.0, float(COMPLETION_WEIGHT))]`.
    - Initial guess: `x0 = [float(COMPLETION_WEIGHT)/2, float(COMPLETION_WEIGHT)/2]`.
    - Convert solver output back to Decimal for `weights` (quantize to 6 dp).
    - Compute `achieved_betas` from final weights.
    - `success = bool(result.success)`.
