## Spacing Scale

All values are multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, cell gutters |
| sm | 8px | Compact row padding, inline label gaps |
| md | 16px | Default card padding, form field spacing |
| lg | 24px | Section padding, card-to-card gap |
| xl | 32px | Page header margin, sidebar section breaks |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level vertical rhythm |

Exceptions:
- Touch targets for interactive icon buttons: minimum 44px x 44px (accessibility minimum, not layout token)
- Sidebar width: fixed 240px (not a spacing token — structural constant)

## Responsive Approach

Desktop-first. Minimum supported viewport: 1024px wide.

- Sidebar: fixed left, 240px wide, always visible at >= 1024px
- Main content: `calc(100vw - 240px)` wide, left-offset 240px
- No mobile breakpoints in Phase 8 (deferred per CONTEXT.md)
- Tables: no horizontal scroll at 1024px minimum; columns drop to fit if needed via `table-layout: fixed`

## Application Shell

### Layout Structure

```
RootLayout (layout.tsx — dark, Inter)
  AppShell (Client Component)
    Sidebar (fixed left, 240px, bg #0A1628, border-right 1px #0F2040)
      Logo ("PEAD" — 16px semibold, #2471A3)
      NavLinks (8 links — active state: left border 2px #2471A3, text white; inactive: text #6B8EAD)
        "/" — Dashboard
        "/signals" — Signal Feed
        "/positions" — Positions
        "/rl" — RL Console
        "/backtest" — Backtest
        "/alerts" — Alerts
        "/settings" — Settings
        "/macro" — Macro
      SSEStatusDot (bottom of sidebar — green dot when connected, red when disconnected)
    MainContent (left-margin 240px, min-height 100vh, bg #0A1628)
      {page children}
```

### SSE Connection

- `useSSE` hook lives in `src/hooks/useSSE.ts`
- Single `EventSource` instance opened at `GET /api/v1/events`
- Shared via React Context (`SSEContext`) so all views read the same connection
- Reconnect: EventSource reconnects automatically on disconnect
- On reconnect: log to console, show `SSEStatusDot` as red for the duration of disconnect
- Heartbeat comments (`: heartbeat`) are silently ignored by EventSource

### View 1: Dashboard (`/`)

**Purpose:** At-a-glance operational status — NAV, daily P&L, active positions, macro gate, last 5 alerts.

#### Component Tree

```
DashboardPage (Server Component — fetches initial REST data)
  DashboardClient (Client Component — receives initial props, subscribes to SSE)
    PageHeader ("Dashboard")
    KPIGrid (4 cards, 2-column on left, 2-column on right)

      KPICard: "Daily P&L"
      KPICard: "Open Positions"
      KPICard: "Macro Gate"
    LastAlertsPanel (last 5 alerts, polling or SSE-patched)
      AlertRow x5
```

#### KPI Card Spec

Each card: bg `#0F2040`, padding 24px, border-radius 8px, border 1px `#1A3050`.

| Card | Label | Value format | Color logic |
|------|-------|-------------|-------------|
| Portfolio NAV | "Portfolio NAV" | `$1,234,567.89` — JetBrains Mono 28px 700 | White always |
| Daily P&L | "Daily P&L" | `+$2,341.00 (+1.23%)` — JetBrains Mono 28px 700 | `#27AE60` if >= 0, `#E74C3C` if < 0 |
| Open Positions | "Open Positions" | `7` — JetBrains Mono 28px 700 | White always |
| Macro Gate | "Macro Gate" | `OPEN` or `GATED` — Inter 20px 600 | `#27AE60` if OPEN, `#E67E22` if GATED |

KPI card label: Inter 12px weight 500 `#6B8EAD`, uppercase, letter-spacing 0.08em.
KPI card value: JetBrains Mono (except Macro Gate which uses Inter).

#### Last 5 Alerts Panel

- Panel title: "Recent Alerts" — Inter 14px 500 `#6B8EAD`
- Each row: event_type badge + payload summary (first 80 chars) + timestamp (relative: "2m ago")
- Row height: 44px, border-bottom 1px `#1A3050`
- SSE `alerts` channel events prepend new rows and trim to 5 visible

#### Data Shape

```typescript
interface DashboardData {
  nav: number;           // total portfolio NAV in USD
  daily_pnl: number;     // absolute dollar P&L today
  daily_pnl_pct: number; // percentage P&L today
  open_positions: number;
  macro_gate: "OPEN" | "GATED";
  macro_score: number;   // composite score -6 to 0
  recent_alerts: AlertSummary[];
}

interface AlertSummary {
  id: string;
  event_type: string;
  payload_summary: string; // first 80 chars of payload as string
  created_at: string;      // ISO 8601
  delivered_sendgrid: boolean;
  delivered_slack: boolean;
}
```

#### REST Endpoint

`GET /api/v1/dashboard` — returns `DashboardData`. Server Component fetches this with `cache: 'no-store'`.

#### SSE Patches

- `alerts` channel: prepend new `AlertSummary` to `recent_alerts`, trim to 5
- `positions` channel: update `open_positions` count
- No direct NAV or P&L SSE channel — those refresh on next dashboard REST poll (30s interval via `setInterval`)

#### Skeleton State

4 KPI cards each show a `SkeletonRect` (bg `#1A3050`, border-radius 8px, 80px tall, pulsing opacity 0.4-1.0 at 1.5s). Alert rows show 5 `SkeletonLine` elements.

```typescript
interface RLStateData {
  agents: AgentRewardSeries[];
  regime_weights: RegimeWeights;
  last_checkpoint_step: number;

interface AgentRewardSeries {
  agent_id: number;  // 0-4
```

## SSE Architecture Details

### useSSE Hook

File: `src/hooks/useSSE.ts`

```typescript
// Signature
function useSSE(channel: "signals" | "positions" | "rl_state" | "alerts"): {
  lastEvent: unknown;
  connected: boolean;
}
```

- Single shared `EventSource` at `GET /api/v1/events` managed via `SSEContext`
- Context provides: `{ addListener(channel, cb), removeListener(channel, cb), connected: boolean }`
- Each call to `useSSE(channel)` registers/unregisters a listener for that channel
- `EventSource` opened once in `SSEProvider` (Client Component wrapping `AppShell`)
- On `onerror`: set `connected = false`; EventSource auto-reconnects; set `connected = true` on next `onopen`

### SSE Event Format (from stream.py)

```
event: signals\n
data: {"event":"signal_generated", ...}\n
\n
```

EventSource client listens per named event:

```typescript
eventSource.addEventListener("signals", (e) => { /* parse e.data */ });
eventSource.addEventListener("positions", (e) => { /* parse e.data */ });
eventSource.addEventListener("rl_state", (e) => { /* parse e.data */ });
eventSource.addEventListener("alerts", (e) => { /* parse e.data */ });
```
