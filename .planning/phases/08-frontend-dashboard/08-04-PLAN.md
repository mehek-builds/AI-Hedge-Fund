<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser form -> PATCH /api/v1/settings | User-supplied numeric values sent to mutate global runtime config |
| Browser -> POST /api/v1/settings/reset | Destructive action requiring inline confirmation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-11 | Tampering | PATCH /api/v1/settings numeric fields | mitigate | Frontend: HTML input min/max attributes. Backend: Pydantic validators enforced in settings_router.py with 422 on violation. Frontend reverts on 4xx response. |
| T-08-12 | Tampering | POST /api/v1/settings/reset | mitigate | Inline confirmation gate in UI ensures intentional click. Only resets to hardcoded safe defaults (0.02, 0.04, False, 10). |
| T-08-13 | Information Disclosure | /api/v1/macro endpoint | accept | Macro indicator values are market data, not secrets. No PII. Phase 9 can add API key auth. |
| T-08-14 | Spoofing | Settings optimistic update | mitigate | Values revert on any non-ok HTTP response. savedValues snapshot preserves last confirmed server state. |
</threat_model>
