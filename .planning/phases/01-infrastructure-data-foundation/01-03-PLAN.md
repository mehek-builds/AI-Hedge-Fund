Create `.github/workflows/deploy.yml`:

```yaml
name: Deploy to Railway

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    # Per-service deploy. rl_trainer is INTENTIONALLY OMITTED — manual deploy only (CLAUDE.md NFR-2).
    strategy:
      matrix:
        service: [db, redis, fastapi, celery_worker, prefect_server, nextjs]
    steps:
      - uses: actions/checkout@v4
      - name: Install Railway CLI
        run: npm install -g @railway/cli
      - name: Deploy ${{ matrix.service }} to Railway
        run: railway up --detach --service ${{ matrix.service }}
        env:
          RAILWAY_TOKEN: ${{ secrets.RAILWAY_TOKEN }}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner -> Railway | Token-authenticated deploy crosses public internet |
| Railway dashboard -> production env vars | Human-typed secrets enter Railway's vault |
| main branch push -> auto-deploy | Anything merged to main reaches production |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | RAILWAY_TOKEN in GitHub secrets | mitigate | Stored as GitHub Actions secret (encrypted at rest, never echoed in logs); rotate quarterly via Railway dashboard |
| T-03-02 | Tampering | rl_trainer auto-deploy would kill training | mitigate | rl_trainer EXPLICITLY OMITTED from deploy.yml matrix; runbook documents auto-deploy=off in Railway settings |
| T-03-03 | Information Disclosure | secrets in CI logs | mitigate | All secret refs use `${{ secrets.RAILWAY_TOKEN }}` (auto-masked by GitHub Actions); no `echo $RAILWAY_TOKEN` |
| T-03-04 | Denial of Service | Railway ephemeral filesystem wipes db on restart | mitigate | Volume attached at `/var/lib/postgresql/data` BEFORE first deploy; FR-1.3 acceptance test (restart -> hypertables still 6) gates the human checkpoint |
| T-03-05 | Tampering | malicious push to main auto-deploys | accept | Single-developer repo (NFR-5); branch protection deferred to Phase 9 hardening |
| T-03-06 | Information Disclosure | DATABASE_URL contains password | mitigate | Set as Railway env var only; `.env` in `.gitignore` (Plan 01-01); never logged in workflow steps |
</threat_model>
