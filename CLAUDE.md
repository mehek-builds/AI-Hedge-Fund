## Critical Architecture Decisions

**SSE not WebSocket** for real-time dashboard — SSE survives Railway's proxy, requires no upgrade handshake. FastAPI `StreamingResponse` + Redis pub/sub fan-out. All dashboard components that subscribe are Client Components (`'use client'`).

**PER buffer in PostgreSQL**, not Redis — 100k transitions × 64-dim state exceeds Railway Redis memory ceiling by ~10×. Use `rl_transitions` TimescaleDB hypertable with `priority` column.

**Celery tasks are synchronous** — no `async def` in Celery tasks. Use `asyncio.run()` for any async helpers called from workers.

**TimescaleDB on Railway = custom Docker service** — Railway has no managed TimescaleDB. Use `timescale/timescaledb:latest-pg15` with a persistent volume mounted at `/var/lib/postgresql/data`. Volume must be attached before first `CREATE TABLE` — ephemeral filesystem wipes data on restart.

**RL trainer on manual deploy only** — Railway auto-deploy kills running training jobs. RL trainer service must NOT be connected to GitHub auto-deploy. Checkpoint every 1,000 steps to PostgreSQL.

**Alembic + TimescaleDB** — exclude `_timescaledb_*` internal tables from autogenerate. Hypertable creation via `op.execute()` raw SQL in migrations, not autogenerated DDL.

**SAC ensemble anti-collapse** — 5 agents require: per-agent seeds, ±30% hyperparameter perturbation, separate PER buffers. Monitor pairwise cosine similarity; alert if > 0.9. Cannot be retrofitted after training starts.

**Point-in-time data** — all records tagged with `ingestion_timestamp`. FRED must use ALFRED vintage API (not standard API — returns revised values). FMP earnings stored with `ingestion_timestamp` and never overwritten. S&P 500 constituent history is a membership table, not a current snapshot.

**Bracket orders via `alpaca-py`** — `OrderClass.BRACKET` with limit entry + stop-loss leg + nominal take-profit ceiling. Build bracket orphan detector before first live order: any open exit order with no corresponding position → cancel and alert.

## Signal Logic (Shepherd PEAD)

```
market_implied_eps = price / sector_median_forward_pe  # NOT analyst consensus
eps_gap = (market_implied_eps - actual_eps) / abs(actual_eps) * 100

# Entry requires all 3 axes:
# 1. Valuation: eps_gap positive and above sector hurdle rate
# 2. Operating: quality_score > threshold (revenue + margin + share count + guidance)
# 3. Momentum: 1-month and 3-month price momentum positive

final_size = structural_active_weight × macro_multiplier × rl_conviction
```

Macro gate: 1.0× (score 0 to −1), 0.6–0.7× (−2 to −3), 0.2–0.3× (−4 to −6)
ERP cap: 0.8× when E/P < real TIPS 10Y yield
Hard stop: 8% from entry, position-level, independent of RL
